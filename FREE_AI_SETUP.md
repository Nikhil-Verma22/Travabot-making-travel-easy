# 🆓 FREE AI ALTERNATIVES SETUP

## 🎯 BEST OPTIONS FOR JUDGES (No Cost)

### Option 1: Hugging Face (RECOMMENDED) ⭐

**Why:** 100% free, no credit card, easy setup

1. **Get API Key:**
   - Go to [huggingface.co](https://huggingface.co)
   - Sign up (free)
   - Go to Settings → Access Tokens
   - Create new token

2. **Set in Supabase:**
   ```
   HUGGINGFACE_API_KEY=hf_your_token_here
   ```

### Option 2: Google Gemini (FREE TIER)

**Why:** Google's free AI, good for travel planning

1. **Get API Key:**
   - Go to [ai.google.dev](https://ai.google.dev)
   - Get API key (free tier)

2. **Set in Supabase:**
   ```
   GEMINI_API_KEY=your_gemini_key_here
   ```

### Option 3: Groq (FAST & FREE)

**Why:** Super fast inference, generous free tier

1. **Get API Key:**
   - Go to [console.groq.com](https://console.groq.com)
   - Sign up (free)
   - Get API key

2. **Set in Supabase:**
   ```
   GROQ_API_KEY=your_groq_key_here
   ```

### Option 4: Ollama (LOCAL - COMPLETELY FREE)

**Why:** No API costs ever, runs on your computer

1. **Install Ollama:**
   ```cmd
   # Download from ollama.ai
   ollama pull llama2
   ollama serve
   ```

2. **No API key needed** - runs locally!
